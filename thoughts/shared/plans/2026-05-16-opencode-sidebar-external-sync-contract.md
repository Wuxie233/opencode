# OpenCode Sidebar External Sync Interface Contract

**Status:** frozen (implementers and reviewers MUST conform; changes require user approval)

## Scope and Security Invariants

- Sync only the left sidebar project-list state: opened projects, ordering, expanded flags, and lastProject per namespace/scope.
- Never sync `server.list`, credentials, passwords, tokens, model config, sessions, prompts, provider auth, or historical `/project` full list.
- Payloads are whitelist-built by clients and whitelist-validated by the service.
- Logs and errors may include endpoint names, status codes, namespace, scope, version, and deviceId, but never token values, pairing secrets, raw persisted stores, or rejected payload bodies.
- Legacy browser storage keys are read as fallback only. The client must not delete or mutate legacy keys except by writing the current compatible key.

## HTTP Endpoints

| Method | Path | Auth | Description |
|--------|------|------|-------------|
| POST | /sidebar-sync/pairing | none | Create a short-lived pairing code for the restart page. |
| POST | /sidebar-sync/pairing/:code/claim | none | Exchange a pairing code for a device token. |
| GET | /sidebar-sync/state/:namespace/:scope | Bearer device token | Fetch the latest sidebar state. |
| PUT | /sidebar-sync/state/:namespace/:scope | Bearer device token | Upload sanitized sidebar state using version conflict detection. |
| GET | /restart | none | Serve the download, installation, and pairing page. |
| GET | /restart/opencode-sidebar-sync.user.js | none | Serve the userscript fallback artifact. |
| GET | /restart/opencode-sidebar-sync-extension.zip | none | Serve the extension artifact zip when available. |
| GET | /restart/manifest.json | none | Serve release metadata and artifact hashes. |

## Request and Response Schemas

### Shared Types

```ts
export interface SidebarProjectState {
  readonly worktree: string
  readonly expanded: boolean
}

export interface SidebarStatePayload {
  readonly schemaVersion: 1
  readonly projects: readonly SidebarProjectState[]
  readonly lastProject?: string
}

export interface SidebarStateEnvelope {
  readonly namespace: string
  readonly scope: string
  readonly version: number
  readonly updatedAt: string
  readonly updatedByDeviceId: string
  readonly payload: SidebarStatePayload
}

export interface PairingCreatedResponse {
  readonly code: string
  readonly expiresAt: string
}

export interface DeviceTokenResponse {
  readonly deviceId: string
  readonly token: string
  readonly expiresAt?: string
}
```

### POST /sidebar-sync/pairing

Request body:
```ts
interface CreatePairingRequest {
  readonly label?: string
}
```

Response 200:
```ts
type CreatePairingResponse = PairingCreatedResponse
```

Error responses: 400 ValidationError, 500 InternalError

### POST /sidebar-sync/pairing/:code/claim

Request body:
```ts
interface ClaimPairingRequest {
  readonly deviceName?: string
}
```

Response 200:
```ts
type ClaimPairingResponse = DeviceTokenResponse
```

Error responses: 400 ValidationError, 404 NotFound, 409 PairingExpired, 500 InternalError

### GET /sidebar-sync/state/:namespace/:scope

Response 200:
```ts
type GetSidebarStateResponse = SidebarStateEnvelope
```

Response 204: no state exists yet for this namespace/scope.

Error responses: 401 Unauthorized, 404 NotFound, 500 InternalError

### PUT /sidebar-sync/state/:namespace/:scope

Request body:
```ts
interface PutSidebarStateRequest {
  readonly baseVersion: number
  readonly payload: SidebarStatePayload
}
```

Response 200:
```ts
type PutSidebarStateResponse = SidebarStateEnvelope
```

Response 409:
```ts
interface SidebarConflictResponse {
  readonly error: "VersionConflict"
  readonly current: SidebarStateEnvelope
}
```

Error responses: 400 ValidationError, 401 Unauthorized, 409 VersionConflict, 500 InternalError

## Browser Storage Contract

OpenCode currently persists server sidebar state at:

- Current key: `opencode.global.dat:server`
- Legacy key: `server.v3`

Only these paths inside parsed storage are in sync scope:

```ts
interface CurrentServerPersistedShape {
  readonly projects?: Record<string, readonly SidebarProjectState[]>
  readonly lastProject?: Record<string, string>
}
```

The extension/userscript must preserve every other key in the parsed persisted object when writing current storage, but it must never upload those other keys to the service.

## Namespace and Scope

- `namespace`: personal pairing namespace generated by the sync service and encoded in the device token.
- `scope`: OpenCode server origin scope matching the existing `server.tsx` behavior: `local` for sidecar/localhost, otherwise the active server key string.

## Error Code Conventions

| Code | Meaning | Response shape |
|------|---------|----------------|
| 400 | Validation failure or forbidden field present | `{ error: "ValidationError", fields: Record<string, string> }` |
| 401 | Missing or invalid auth | `{ error: "Unauthorized" }` |
| 404 | Pairing/state resource not found | `{ error: "NotFound", resource: string }` |
| 409 | Version or pairing state conflict | `{ error: string, current?: SidebarStateEnvelope }` |
| 500 | Server error | `{ error: "InternalError" }` |
